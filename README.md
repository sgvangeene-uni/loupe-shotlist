# loupe-shotlist

The shotlist app for the phone, from Loupe Flow. GitHub Pages serves it at
https://sgvangeene-uni.github.io/loupe-shotlist/.

- Only the app's files are here: no shotlists, no ticks, no addresses, no keys.
  The app asks for the site's address and a one-time code when it is linked;
  the lists and ticks go only between the phone and that site.
- The source is `phone/` in the site's repository; these files are built from
  it with `node tools/build-shotapp.mjs DIR`. Do not edit them here.
